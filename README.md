# 🚀 DevOps Practicals

This repository contains **self-designed DevOps practicals** created to understand and practice
core DevOps concepts beyond college syllabus requirements.

The goal of this repository is to gain **hands-on experience** with DevOps tools, workflows,
and automation techniques used in real-world software development and deployment.

## Last updated on 13th of September 2026

---

## 🎯 Objectives

- Understand DevOps fundamentals and culture
- Practice CI/CD pipelines
- Learn containerization using Docker
- Explore automation and infrastructure concepts
- Bridge the gap between development and operations

---

## 🧰 Tools & Technologies

- Git & GitHub
- Linux Basics
- Docker
- GitHub Actions (CI/CD)
- YAML Configuration
- Bash Scripting
- Cloud & Deployment Concepts (Intro level)
