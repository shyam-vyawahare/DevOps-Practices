# AWS EC2 + Docker Deployment

## 🎯 Objective

Deploy a Dockerized application on an AWS EC2 instance.

This practical connects the DevOps workflow learned so far:

```text
Developer
   ↓
GitHub
   ↓
GitHub Actions
   ↓
Docker Image
   ↓
GitHub Container Registry (GHCR)
   ↓
AWS EC2
   ↓
Running Docker Container
   ↓
Public Application
```
